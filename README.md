# 向彦瑾 · Yanjin Xiang

Personal academic homepage of Yanjin Xiang, a PhD student in the Department of Statistics, School of Mathematical Sciences, Peking University (since 2024).

Website: https://xiangyanjin.github.io/

This is a bilingual Chinese–English static website. The source consists of `index.html`, `styles.css`, and `script.js`; no build or dependencies are required. GitHub Pages serves the `main` branch from the repository root.

The homepage includes research interests, six public preprints with topic filters and bilingual overviews, education, and selected honors. Education and honors were selected from the author's CV; the original CV is not hosted. Language preferences are saved locally in the browser. All paper links and background information remain accessible without JavaScript.
